# 09/14/2026 [Samsung领投Nvidia AI芯片竞争对手](https://www.cnbc.com/2026/09/14/samsung-euclyd-ai-chip-funding.html)
特邀评论员：Perplexity(Perplexity AI, Inc)  

## 新闻回顾

荷兰 AI 芯片初创公司 **Euclyd** 完成 2 亿欧元（约 2.3 亿美元）A 轮融资。该轮融资由 **Samsung（三星）**、Somerset Capital Partners、EQT 管理的 Scaleup Europe Fund 与 Innovation Industries 共同领投。

Euclyd 成立于 2024 年，目标不是推出另一款通用 GPU，而是设计一套面向 **AI 推理（inference）** 的专用芯片系统，并同时覆盖处理器和内存架构。公司声称，其面向 **基础模型（foundation models）** 的硅系统可以降低 AI 数据中心的能耗与总体成本。

该公司计划形成两条商业路径：

- 向希望私有化部署、重视数据安全的企业销售物理芯片与机架级 AI 推理系统
- 对希望基于既有技术自行造芯片的公司授权其 **IP（知识产权）**

Euclyd 希望在 2028 年开始交付实体芯片系统，并在 2030 年服务数千家企业客户。三星的价值不仅是资金：其 DRAM、HBM 等存储器制造能力、系统工程经验、供应链能力和客户网络都可能影响 Euclyd 是否能完成从架构概念到量产交付的跨越。

这轮融资发生在 GPU 替代方案快速升温的背景下。NVIDIA 凭借 CUDA 软件生态和高端 AI GPU 在训练与推理市场取得主导地位；与此同时，OpenAI 的 Jalapeño、Google TPU、AWS Trainium/Inferentia、Meta 自研加速器，以及一批初创公司都在尝试以专用架构降低推理成本。Euclyd 目前仍未在大规模商业部署中验证其系统能力。 

## 技术分解

### Q：为什么“推理芯片”会成为 AI 硬件的新战场？

**训练** 是用海量数据和算力更新模型权重；**推理** 则是把完成训练的模型用于实际请求，例如聊天生成、代码补全、搜索排序、图像生成和企业 Agent 工作流。

推理的需求正在转向以下问题：

| 维度 | 训练优先 | 推理优先 |
|---|---|---|
| 核心目标 | 尽快完成模型训练、缩短训练周期 | 降低每个 token、请求或任务的服务成本 |
| 典型并行模式 | 大规模数据并行、张量并行、流水线并行 | 小批量或动态批量、低延迟调度、KV Cache 管理 |
| 关键瓶颈 | 浮点/张量计算、跨节点互连、HBM 容量与带宽 | 内存带宽、模型权重搬运、KV Cache 容量、尾延迟、功耗 |
| 客户关注点 | 时间到结果、训练吞吐、可扩展性 | token/s、首 token 延迟、每 token 成本、每瓦性能、可部署性 |
| 硬件选择 | 通用高端 GPU 通常更具弹性 | ASIC、推理 GPU、NPU、定制化系统更有机会 |

大语言模型推理并不只是“矩阵乘法”。在 **prefill** 阶段，系统需要对输入上下文进行较大规模并行计算；在逐 token 的 **decode** 阶段，计算通常更容易落入访存、KV Cache 读取和调度开销主导的状态。对于长上下文、多用户并发、MoE 模型或 Agent 循环，内存系统与软件调度往往决定实际单位成本。

因此，Euclyd 强调同时改造“处理器和内存架构”，理论上是在尝试绕开 GPU 的一部分通用性成本，针对推理的访存和数据移动路径做更激进的系统级优化。  

### Q：Euclyd 的“不同于 GPU 的架构”可能意味着什么？

新闻没有披露 Euclyd 的 ISA、计算阵列、制程节点、封装、片间互连、存储层级、编程模型或软件栈，因此不能把“不同于 GPU”直接等同于性能领先。

从行业常见路径看，这种表述通常可能包括：

- 使用针对 Transformer 推理定制的计算数据流，例如更强的矩阵乘法阵列、systolic array、数据流架构或专用张量核心
- 为模型权重和 KV Cache 优化片上 SRAM、HBM、DDR、CXL 内存扩展或内存压缩方案
- 使用低精度数据格式，例如 FP8、FP6、INT8、INT4，甚至量化感知的混合精度执行
- 尝试提高内存带宽利用率，减少权重、激活值和 KV Cache 在不同层级之间的反复搬运
- 以机架系统而非单芯片为单位设计，联合优化电源、冷却、网络、存储与推理调度
- 面向固定或受约束模型族优化，牺牲通用 GPU 的一部分灵活性，换取吞吐、能效和成本

但架构创新需要转化为可交付系统。真正的竞争问题不是“芯片算力峰值是否更高”，而是：给定真实模型、上下文长度、并发度、精度要求和 SLA 后，系统是否能以更低总拥有成本稳定运行。

### Q：Euclyd 主要在和谁竞争？

| 竞争者类别 | 代表 | 优势 | 对 Euclyd 的挑战 |
|---|---|---|---|
| 通用 AI GPU 平台 | NVIDIA Blackwell 系列及后续平台 | CUDA 生态、成熟开发工具、广泛框架支持、网络与整机集成能力 | Euclyd 必须证明迁移成本和软件风险值得客户放弃 GPU 的灵活性 |
| 云厂商自研芯片 | Google TPU、AWS Trainium/Inferentia、Meta 自研加速器 | 有稳定内部负载，可将芯片、网络、编译器和数据中心协同优化 | 云厂商既是潜在客户，也更可能选择自己掌控路线 |
| AI 芯片初创公司 | 各类推理 ASIC、数据流加速器、RISC-V/NPU 方案 | 可针对特定推理痛点进行架构创新 | 技术同质化、融资周期、量产风险与客户导入难度都很高 |
| 企业私有化部署方案 | GPU 服务器、推理 appliance、边缘 AI 系统 | 客户已有采购与运维习惯，软件兼容性相对成熟 | Euclyd 需要提供完整的模型部署、监控、安全和运维体验 |
| IP 授权公司 | Arm、各类 NPU/互连/存储 IP 供应商 | 商业模式轻、可借助客户的 SoC 与量产资源 | Euclyd 需要证明其 IP 可综合、可验证、可移植且有明确性能收益 |

Euclyd 的定位并不是直接与 NVIDIA 在所有工作负载、所有规模和所有客户类型上正面交锋。更现实的切入点是：对模型、精度、吞吐和部署位置相对可控的企业推理场景，尤其是数据不能出域、希望自托管、且长期推理负载足够稳定的客户。

### Q：三星参与融资，技术上最有价值的部分是什么？

新闻中 Euclyd CEO 特别强调三星的存储器、系统工程和供应链能力。对于 AI 推理芯片公司，这一点非常关键。  

- **存储器供给与路线协同**：大模型服务常受模型权重和 KV Cache 的存储容量、带宽与功耗限制。三星是主要存储器制造商之一，理论上可在 HBM、DRAM、先进封装接口或系统内存配置方面提供协同空间
- **量产供应链能力**：初创公司最容易低估的环节包括封装、基板、测试、良率、内存配额、板卡验证、机架集成与交付服务。三星的产业网络可能降低部分供应链不确定性
- **系统级共同设计机会**：若 Euclyd 的优势依赖内存架构，单纯采购标准部件未必足够；与存储供应商更深的联合定义可能比独立芯片设计更有意义
- **市场背书**：三星的参与能够提高后续融资、客户接触和产业合作的可信度

不过，三星的投资不等于三星承诺代工、提供独家 HBM、协助先进封装，或对 Euclyd 的性能指标背书。报道只说明三星参与领投，并未披露制造、供货、联合研发或商业采购协议。  

### Q：Euclyd 的两条商业模式是否互相矛盾？

不必然矛盾，但执行难度很高。

| 模式 | 销售机架级硬件系统 | 授权芯片 IP |
|---|---|---|
| 收入逻辑 | 售卖板卡、服务器或机架，获得系统收入与后续服务收入 | 授权费、NRE、版税或定制设计收入 |
| 优点 | 可直接控制端到端性能、交付体验和客户关系 | 资本开支相对轻，可借客户的 SoC、制造与渠道能力扩张 |
| 难点 | 需要硬件供应、认证、软件、运维、售后和库存能力 | 需要成熟的 RTL、验证、PPA 数据、软件 SDK 和长期客户支持 |
| 技术要求 | 系统软件、集群调度、散热、电源、网络和部署工具完整 | IP 模块化、可移植、可综合、可验证，并适配多个工艺与客户 SoC |
| 主要风险 | 资金消耗大，交付延期会迅速损害信誉 | 客户验证周期长，且客户可能要求高度定制化 |

从创业阶段看，先以机架系统验证性能、形成真实推理 workload 数据，再把成熟模块 IP 化，是合理路径；但若在软件、硬件和 IP 客户支持都尚未成熟时同时推进，可能出现资源分散。

### Q：报道中最需要保留判断的地方是什么？

- **尚无规模化部署验证**：报道明确指出 Euclyd 的系统还未经过大规模商业部署验证。性能、可靠性、兼容性、供应能力、单位成本和客户迁移成本均未被公开证明。  
- **没有公开基准**：未披露与 NVIDIA GPU、TPU 或其他 ASIC 对比的模型、batch size、上下文长度、精度、吞吐、首 token 延迟、decode 延迟、功耗或总拥有成本
- **“能效更高”不等于“业务成本更低”**：推理成本还包括服务器利用率、软件开发、模型转换、运维、人力、故障恢复、机房改造、供应风险和折旧
- **软件生态可能比硬件更难**：客户需要 PyTorch、ONNX、TensorRT 类工具链、主流模型兼容、量化工具、编译器、分布式运行时、监控与调试能力。没有开发者体验，性能优势难以变成订单
- **2028 年产品落地存在时间风险**：AI 加速器迭代快。若 Euclyd 在 2028 年才开始推送实体系统，届时 NVIDIA、云厂商和其他 ASIC 厂商的硬件与软件能力都会继续演进。  

## 新闻分析

### Euclyd：高差异化机会，对应高执行风险

**有利因素**

- 获得约 2.3 亿美元 A 轮资金，对一家 2024 年成立、尚未量产的欧洲芯片初创公司而言是显著资本支持
- 选择推理而非全面复制训练 GPU 路线，聚焦了更具成本敏感性、需求持续增长的细分市场
- 将硬件系统销售与 IP 授权并列，可在“直接服务企业”和“进入其他芯片设计”之间寻找规模化路径
- 三星参与有助于补足创业公司在存储、供应链和系统工程上的天然短板

**不利因素**

- AI 芯片不是单点架构竞赛，而是软件栈、先进封装、内存供给、系统网络、验证、制造和客户服务的综合战争
- 2.3 亿美元虽大，但如果公司要完成复杂芯片流片、软件栈、板卡、机架系统、客户验证和规模交付，资金消耗也会非常快
- 企业自托管市场重视安全与控制权，但采购决策通常保守；新平台必须跨过兼容性、服务能力和长期供货保障门槛
- IP 授权客户往往要求可验证、可移植、可定制的成熟资产，这与“仍在开发产品”的初创阶段存在节奏冲突

Euclyd 最需要证明的不是“能做出芯片”，而是某个目标模型在真实 SLA 下能实现明确的每 token 成本优势，并且客户能够以可接受的工程成本迁移和长期运维。

### 三星：以小额资本换取 AI 基础设施战略期权

**可能收益**

- 三星可通过投资接触新型推理架构，从而扩大其存储产品在 AI 系统中的潜在需求，特别是高带宽内存和大容量内存层级
- 若 Euclyd 的架构高度依赖内存创新，三星可获得未来联合优化、部件供应、封装协同或系统合作的机会
- 在 NVIDIA GPU 需求极强的环境中，支持替代性加速器有助于避免 AI 基础设施价值完全向单一 GPU 供应链集中
- 欧洲 AI 芯片创业公司与 Scaleup Europe Fund 等资本共同参与，也让三星获得区域技术生态的观察窗口

**可能代价**

- 若 Euclyd 无法量产或缺乏软件生态，投资的战略价值会有限
- 若三星同时服务多家加速器厂商，很难仅凭一家被投公司形成排他性优势
- 先进 AI 内存和系统业务的核心竞争依然在产品路线、良率、客户认证和供给能力；财务投资本身不能替代这些基本功

三星的合理策略不是押注 Euclyd 必然战胜 NVIDIA，而是用相对有限的资本获得未来 AI 推理架构分化时的合作选项。

### NVIDIA：短期影响有限，长期需防范碎片化

**短期来看**，Euclyd 还未实现规模化商用，预计 2028 年才开始交付实体系统，因此不会立即改变 NVIDIA 在高端 AI 加速器领域的主导位置。NVIDIA 的护城河包括硬件、CUDA、编译器、通信库、框架支持、开发者习惯和整机系统能力，而不只是 GPU 算力。

**长期来看**，Euclyd 与云厂商自研芯片、OpenAI 的 Jalapeño 等趋势共同指向一个风险：AI 推理可能逐步从“默认购买通用 GPU”转向“按模型、延迟、成本和部署位置选择专用硬件”。  

这不必然削弱 NVIDIA 的绝对收入，因为 AI 总需求仍可能快速增长；但它会压缩某些固定推理场景中 GPU 的溢价空间，并促使客户提高多供应商和自研芯片比例。

### 企业客户：私有化推理有吸引力，但不能只看峰值性能

对金融、医疗、政府、工业和大型企业而言，在本地或私有数据中心运行 AI 推理可能带来数据主权、合规、延迟控制和可预测成本等收益。Euclyd 的机架级产品若成立，潜在卖点就是“安全自托管推理”。

客户真正应验证的项目包括：

- 自己的核心模型能否在该平台稳定运行，包括长上下文、RAG、Agent、多模态或 MoE 负载
- 是否支持所需精度、量化策略、KV Cache 管理、并发控制和多租户隔离
- 与现有 PyTorch、ONNX、Kubernetes、监控、安全和运维体系的集成成本
- 每 token 成本、功耗、设备利用率和服务等级协议，而非营销材料中的理论 TOPS
- 芯片供货、维修、备件、固件更新、漏洞响应与长期软件支持能力
- 如果供应商融资、量产或路线图出现问题，是否存在可行的迁移与退出方案


| 角度 | 结论 |
|---|---|
| 算力 | Euclyd 押注的是推理阶段的能效、内存系统和专用化，而不是与 GPU 在通用训练能力上硬碰硬。机会存在于模型和 SLA 相对稳定的私有化推理场景；成败取决于真实 token 吞吐、延迟、功耗和软件兼容性 |
| 资本 | 约 2.3 亿美元 A 轮提供了穿越首颗芯片、系统研发与客户验证周期的基础，但不足以消除量产、软件生态和供应链风险。三星的价值更接近存储与产业协同的战略期权，而不仅是财务投资 |
| 幻觉 | 最大的“幻觉风险”是把“非 GPU 架构”“更高能效”或“大额融资”直接推导为商业成功。新闻尚未提供公开性能基准、客户部署数据或量产细节；在 AI 芯片领域，未被真实工作负载验证的优势仍只是待证假设 |
