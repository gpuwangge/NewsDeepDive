# 10/24/2026 [RTX5090被批量拆芯改装](https://www.tomshardware.com/pc-components/gpus/leaked-video-exposes-how-chinese-factories-are-stripping-rtx-5090s-to-fuel-ai-custom-partner-cards-to-nvidia-founders-editions-on-the-chopping-block)
特邀评论员：Perplexity(Perplexity AI, Inc)  
责任编辑：Wangge  

## 新闻回顾

Tom’s Hardware 报道，流出的视频展示了中国工厂批量拆解全新 GeForce RTX 5090：从 NVIDIA Founders Edition（FE，公版）和合作伙伴非公版显卡上拆下 GB202 GPU 与 GDDR7 显存，移植至定制 PCB，再安装双槽涡轮散热器（Dual-slot Blower），测试后重新包装，面向 AI 服务器客户交付。改装目的不是提升游戏性能，而是适配多卡服务器的安装空间与排风需求。 

报道将这一灰色供应链与美国零售缺货联系起来，并称部分非公版 RTX 5090 起价已达 8,500 美元。需要区分：视频支持存在批量改装活动，但“每天改装数千张”属于估计；“NVIDIA 停产 RTX 5090、向 RTX PRO 6000 Blackwell 转移资源”属于报道引用的消息，文中没有提供 NVIDIA 官方确认。 

## 技术分解

### Q1：为什么要拆 GPU 和显存，而不只是换散热器？

因为这实际上是一次板级重构，而不只是更换风扇。

报道描述的流程是：拆除原散热器 → 将 GPU 封装与显存从原 PCB 脱焊 → 移植到新 PCB → 安装双槽涡轮散热器 → 测试交付。严格说，“拆芯”不是把裸硅片从封装中取出，而是对焊接在 PCB 上的器件进行返修与移植。 

定制 PCB 可以重新安排器件、供电和连接器位置，让整卡适配目标服务器。不过，原文没有披露 PCB 设计、供电规格、焊接良率或长期可靠性数据，不能仅凭生产线画面判断其达到服务器级质量。

### Q2：双槽涡轮设计解决了什么？又没有解决什么？

它主要解决空间和气流组织，而不是降低 GPU 本身的热量。

- 空间：减少大型非公版散热器占据的槽位，便于多卡并排安装。
- 气流：利用导风结构，将热空气集中向机箱后方排出，减少开放式散热器向机箱内部散热的问题。
- 代价：更紧凑的散热器需要验证风量、静压、噪声及持续负载下的频率表现，不能直接等同于“散热更好”。报道没有给出相关测试。 

RTX 5090 官方整卡功耗为 575W。若八张卡均以这一功耗运行，仅 GPU 就需要约 4.6kW，尚未计入 CPU、内存、风扇及电源损耗。换成双槽并不会消除机柜供电和排热约束。 

### Q3：改装 RTX 5090 能替代专业 AI 显卡吗？

可以承担部分任务，但不能因为外形接近，就视为同等级替代品。

| 项目 | 原版 RTX 5090 | 新闻中的改装 RTX 5090 | RTX PRO 6000 Blackwell Server Edition |
|---|---|---|---|
| 定位 | 消费级旗舰 | 面向服务器部署的改装卡 | 专业服务器 GPU |
| 架构 | Blackwell | 沿用原 GPU | Blackwell |
| CUDA 核心 | 21,760 | 未披露配置变化 | 24,064 |
| 显存 | 32GB GDDR7 | 本次移植流程未证实扩容 | 96GB GDDR7，支持 ECC |
| 功耗 | 官方 575W | 功耗限制与持续频率未披露 | 最高 600W，可配置 |
| 散热与板卡 | 原厂设计 | 定制 PCB、双槽涡轮 | 官方服务器产品设计 |
| 关键区别 | 消费级配置 | 增加移植与验证风险 | 更大显存及官方服务器产品支持体系 |

原版参数来自 NVIDIA；改装卡信息来自报道，未披露项不能直接套用原卡规格或性能。 

专业卡的显存容量是原版 RTX 5090 的三倍，而 CUDA 核心数量并没有三倍差距。这说明两者的价值差异不只是计算单元数量，也在于模型能否装入显存，以及运行环境所要求的可靠性。 

原文还链接了一篇“96GB 改装 RTX 5090”的其他报道，但不能据此认定本次视频中的卡全部扩容到了 96GB。 

### Q4：多插几张卡，就能变成大模型训练集群吗？

不能简单画等号。RTX 5090 官方不支持 NVLink；移植 PCB、换散热器并不会因此获得该互连能力。 

由此带来的任务差异是：

- 独立推理副本：请求可以分散到不同 GPU，对卡间通信的依赖相对较小。
- 模型跨卡切分：需要交换激活值或其他数据，性能更依赖互连和软件实现。
- 多卡训练：除了 GPU 数量，还要考虑梯度同步、主机拓扑及网络。

因此，这类卡可能适合部分推理和可分割任务，但原文没有提供模型、吞吐、延迟或集群扩展效率测试，“可装入服务器”不等于“适合所有 AI 工作负载”。

### Q5：视频能解释 RTX 5090 为什么缺货吗？

只能解释一种需求来源，不能单独证明缺货的主因。

原文把工厂改装、零售库存下降、疑似停产和高价挂牌串联起来，但没有给出改装采购量占总出货量的比例，也没有提供库存时间序列。其“8,500 美元起价”应理解为报道观察到的特定市场报价，而不是所有地区的成交均价。 

最需要保留的区别是：批量改装画面是证据；日产规模、最终客户及其对全球缺货的贡献，仍有待更多数据验证。

## 新闻分析

### NVIDIA：需求扩大，但产品分层更难管理

- 有利：即使最终用户不买专业卡，AI 需求仍在吸收 NVIDIA GPU；消费级硬件成为 AI 算力来源。
- 不利：若改装卡替代部分专业卡采购，会干扰产品分层；非官方板卡发生故障，也可能带来品牌和支持边界争议。
- 尚不能下结论：报道提及的停产与资源转移，不能据此认定是 NVIDIA 针对改装渠道采取的措施。 

### 显卡合作伙伴与改装工厂：价值从整卡品牌转向芯片获取

合作伙伴卖出的显卡被拆解后，原有散热器、PCB 和外观设计不再是最终客户的核心价值；采购者更看重能否拿到 GB202 与显存。

改装工厂则通过采购、返修、定制板卡和测试赚取价差。但其收益取决于买卡成本、移植良率、返修率与保修支出，不能只用成品售价减去散热器成本估算。报道展示了生产与测试环节，没有披露这些经营数据。 

### AI 客户：获得替代供给，但要核算有效成本

对缺乏其他供给渠道的客户，改装卡提供了一条获得 GPU 的路径。但是否划算，需要比较实际报价和目标工作负载，而非默认“消费卡一定便宜”。

尤其当原版单卡报价已被报道推至 8,500 美元时，采购方更应核算持续吞吐、功耗、故障率、停机和维护成本。图形跑分通过，并不能替代长时间 AI 负载、显存稳定性和多卡压力测试。 

### 游戏玩家与零售商：同一颗 GPU 被更高收益用途重新定价

如果 AI 客户愿意支付更高价格，游戏玩家就必须与另一类买家竞争同一批硬件。零售商可能获得更高单卡利润，也可能面对库存波动和价格回落风险。

原文指出，部分搭载 RTX 5090 的整机甚至比单独显卡更便宜。这更像是不同渠道采购成本与库存节奏不一致的表现，不宜直接外推为所有整机都更划算。 

### 算力、资本、幻觉

- 算力：改装提高的是消费级 GPU 的部署适配性，不会自动增加显存、互连能力或单位芯片性能。可装多少卡，与能稳定交付多少有效算力，是两个问题。
- 资本：套利来自不同市场对同一颗 GPU 的支付意愿差异；当进货价、返修成本和停机风险上升，低价算力的优势也可能消失。
- 幻觉：不要把“工厂很忙”推导成“日产规模已证实”，把“显卡很多”推导成“训练效率很高”，或把“零售涨价”全部归因于改装工厂。

这条新闻最值得关注的变化是：GPU 的最终流向，正在更多地由单位芯片的**收益**决定，而不只是由原本的产品定位决定。
