# 10/19/2026 [NVidia RTX Spark实测](https://www.notebookcheck.net/Nvidia-RTX-Spark-Analysis-Finally-an-answer-to-Apple-s-M5-Pro-M5-Max.1422820.0.html)

## 新闻回顾

Notebookcheck 测试了英伟达 RTX Spark N1X 笔记本平台，重点比较 CPU、GPU、游戏、本地 AI 与能效。它结合联发科参与设计的 Arm CPU、Blackwell GPU 和最高 128GB 统一内存，直接进入苹果 M5 Pro／M5 Max、AMD Strix Halo 所在的高性能集成平台市场。 

主要规格与测试背景：

- CPU：台积电 3nm 制程；高配为 20 核，包括 10 个 Cortex-X925 性能核和 10 个 Cortex-A725 能效核。
- GPU：Blackwell GB20B，高配拥有 6,144 个 CUDA 核心，支持 DLSS 5、Frame Generation。
- 内存与互连：最高 128GB LPDDR5X-9400，内存带宽 300GB/s；CPU 与 GPU Tile 通过 600GB/s NVLink 互连。
- 产品区分：另有 18 核 CPU、5,120 核 GPU 版本，但同样使用 N1X 名称。
- 测试机：华硕 ProArt P16，配备高配 N1X、64GB 内存、3K OLED；10 月 18 日更新加入微软 Surface Laptop Ultra 数据。
- 软件环境：Windows on Arm；部分应用和游戏仍依赖 x64 转译。 

核心结论：RTX Spark 的优势是**统一内存**与较强 GPU 的组合，而不是全面领先。其 CPU 明显落后于 M5 Pro／Max，原生图形测试接近高功耗 RTX 5070 Laptop，本地 AI 测试则与 M5 Pro 各有胜负。 


## 技术分解

### Q1：与苹果、AMD 相比，实测处在什么位置？

以下为原文具体测试机成绩，不代表所有同芯片设备；分数越高越好。 

| 测试项目 | RTX Spark N1X：ProArt P16 | 苹果 M5 Pro | 苹果 M5 Max | AMD Ryzen AI Max+ 395：ProArt PX13 |
|---|---:|---:|---:|---:|
| Cinebench 2024 单核 | 130 | 201 | 199 | 116.4 |
| Cinebench 2024 多核 | 1,726 | 2,347 | 2,490 | 1,673 |
| Geekbench 6.7 多核 | 20,296 | 28,436 | 30,057 | 19,364 |
| 3DMark Steel Nomad | 3,134 | 2,323 | 4,386 | 2,019 |
| Cinebench 多核整机能效，分/瓦 | 13.6 | 23.0 | 21.2 | 15.1 |

数据说明：

- CPU：N1X 接近 AMD Strix Halo，但与苹果高端芯片仍有明显距离。
- GPU：Steel Nomad 中，N1X 比 M5 Pro 高约 35%，比 M5 Max 低约 29%；比 Radeon 8060S 高约 55%。
- 能效：集成设计并不自动带来领先能效，N1X 在上述 CPU 多核测试中仍落后于苹果和这台 AMD 测试机。 

### Q2：128GB 内存和 600GB/s NVLink，分别解决什么问题？

两组数字对应不同环节：

| 参数 | 含义 | 不能据此推断什么 |
|---|---|---|
| 最高 128GB 统一内存 | CPU、GPU 使用共享内存池，为大模型和大型素材提供容量空间 | 不代表应用能独占全部容量 |
| 300GB/s 内存带宽 | 芯片访问外部内存的数据通道 | 不能用 NVLink 带宽替代 |
| 600GB/s NVLink | CPU Tile 与 GPU Tile 之间的互连带宽 | 不等于模型读取权重时拥有 600GB/s 内存带宽 |

原文给出了这些规格，但容量、外部内存带宽和片间互连带宽不能混为一谈。大内存首先扩大“能装下什么”的范围，实际速度仍须由具体模型与软件测试确认。 

### Q3：有 Blackwell GPU，为什么游戏仍不如传统 RTX 笔记本稳定？

短板主要出在软件路径，而非只有 GPU 规模。

原生 Arm 图形测试中，N1X 接近 RTX 5070 Laptop；但多数游戏仍需转译，部分游戏无法运行，也有作品出现卡顿。原文测试的《漫威争锋》原生版本，1080p 性能提高约 20%，1% Low 从约 9fps 提升至 29fps，说明平均帧率之外，流畅性也受转译影响。 

《赛博朋克 2077》在 1440p Ultra、关闭 FSR 的测试中：

| 测试平台 | 平均帧率 |
|---|---:|
| RTX Spark N1X：ProArt P16 | 56.8fps |
| RTX 5070 Laptop：XMG Fusion 16 | 65.2fps |
| 苹果 M5 Max | 63.1fps |
| AMD Radeon 8060S：ProArt PX13 | 49.4fps |

这些是整机与软件组合的结果，不是完全隔离变量的 GPU 对比。DLSS 和插帧也不能解决游戏无法启动的问题。 

### Q4：它已经证明自己是更好的本地 AI 电脑了吗？

尚未。

原文使用 MLPerf Client 2.0，涉及 Llama 3.1 8B、Qwen 3 8B，以及代码代理任务；考察首 Token 延迟（TTFT）、生成速度（Tokens/s）和代理执行时间。结果并非 N1X 单方面领先，而是与 M5 Pro 随测试项目交替占优。 

还要注意两个证据边界：

- Geekbench AI 当时在 N1X 上只能运行 CPU 测试，不能据此评价其 GPU AI 能力。
- 测试机只有 64GB 内存，且主要展示 8B 模型成绩，尚不足以证明最高 128GB 配置运行更大模型时的实际收益。 

因此，“容量潜力较大”与“真实工作流更快”需要分开判断。

### Q5：原文有哪些结论需要谨慎使用？

- 功耗口径：能效测试采用外接显示器并测量整机功耗，不是只测 SoC；不能直接将它与 80W TDP 对照。
- 工具成熟度：当时 HWiNFO 无法显示芯片功耗，GPU-Z 会导致崩溃，主要依赖英伟达性能叠加层监控。
- 游戏覆盖：核心对比主要选取《赛博朋克 2077》和《博德之门 3》，不足以覆盖整个游戏库。
- 图表与文字存在出入：正文称游戏能效超过 M5 Pro，但所列数据中，ProArt P16 为 0.585fps/W，低于 M5 Pro 的 0.672fps/W；不能照搬这一概括。 

## 新闻分析

以下为基于实测结果的商业与产品判断，不代表相关公司的公开立场。

### 英伟达与联发科：从卖 GPU 走向争夺整机平台

收益在于，RTX Spark 将 Arm CPU、Blackwell GPU 和大容量内存整合进同一平台。英伟达可以把竞争范围从独立显卡扩大到整个平台；联发科也获得进入高端 PC 的产品入口。 

代价是责任随之扩大：CPU 性能、驱动、应用适配和整机能效都成为产品体验的一部分。GPU 跑分接近 RTX 5070，并不足以抵消所有平台短板。

### 苹果：性能与能效优势仍在，竞争焦点更加具体

M5 Pro／Max 的 CPU 和能效成绩仍有优势，M5 Max 的图形性能也更高；但 N1X 在原生图形测试中超过 M5 Pro，说明 Windows 阵营出现了更有竞争力的高性能集成方案。 

对苹果而言，压力不只是跑分，而是用户是否需要 Windows 软件与英伟达 GPU 工作流。对 N1X 而言，超过 M5 Pro 的部分图形成绩，也不等于取代整台 MacBook Pro。

### AMD、英特尔与高通：受到的冲击不同

- AMD：Strix Halo 是最直接的对手。CPU 多核接近，但 Radeon 8060S 的原生图形成绩落后；AMD 的 x86 路线则避免了这次测试所暴露的 Arm 转译问题。
- 英特尔：测试中的 Panther Lake 在 CPU 多核和 GPU 性能上落后，但部分 CPU 能效表现更好，仍可围绕轻薄与功耗定位竞争。
- 高通：部分 Snapdragon X2 平台的单核与 CPU 能效更好，但图形性能明显落后；Windows on Arm 的竞争不再只围绕轻办公展开。 

### 微软、华硕与用户：机会在差异化，成本在适配

Surface Laptop Ultra 与 ProArt P16 表明，这个平台已经进入具体产品。微软获得更强的 Windows on Arm 图形硬件，华硕获得面向本地 AI 与创作者的差异化配置。 

但现有软件的兼容性不会随硬件发布自动解决。用户应比较实际应用、模型速度、游戏支持和整机价格，而不是只比较 CUDA 核心数。本文也没有提供足够的统一价格口径，不能据此判断谁更划算。

### 最后总结：算力、资本、幻觉

- 算力：RTX Spark 将较强 GPU 与大容量共享内存带入 Arm Windows 笔记本；真正兑现多少性能，取决于原生软件、内存带宽和持续功耗。
- 资本：它扩大了英伟达的平台收入机会，也要求厂商持续投入驱动与应用生态。商业价值最终要由实际效率收益支撑，而非只靠 AI 标签。
- 幻觉：本地运行不等于回答可靠；本文测试的是速度和任务执行时间，并未证明事实准确率提高。同样，不应把“能装下更大模型”包装成“全面超过 M5 Max”。
